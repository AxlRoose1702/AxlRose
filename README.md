# ¡Hola! Soy Axel José Mosquito Andrade 👋

Soy estudiante de Ingeniería en Sistemas y desarrollador **Full Stack .NET** de Guatemala. Tengo experiencia en soporte técnico de TI y en el desarrollo de aplicaciones web utilizando tecnologías del ecosistema Microsoft.

He trabajado en el desarrollo de sistemas con **C#, ASP.NET Core, Blazor Server, Entity Framework Core y SQL Server**, implementando módulos administrativos, autenticación de usuarios, roles, reportes, paneles de indicadores y medidas de seguridad para aplicaciones web.

También tengo experiencia publicando aplicaciones en **IIS**, configurando bases de datos, utilizando control de versiones y resolviendo problemas relacionados con el funcionamiento y despliegue de sistemas.

Actualmente estoy fortaleciendo mis conocimientos en **ASP.NET Core Web API, Docker, CI/CD y servicios en la nube con Azure**.
